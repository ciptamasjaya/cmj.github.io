🎉 Fitur DataTable.js

  • ✅ Sorting - Klik header kolom untuk sort
  • ✅ Pagination - Navigasi halaman dengan mudah
  • ✅ Search/Filter - Cari data secara real-time
  • ✅ Responsive - Mobile-friendly (resize browser untuk test)
  • ✅ Export - Download data ke CSV atau PDF
  • ✅ Vanilla JS - Tanpa jQuery atau dependencies

    info: 'Menampilkan {start} sampai {end} dari {rows} data'
  }
});
