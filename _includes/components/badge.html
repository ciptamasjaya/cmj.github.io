Bootstrap 5 badge variants (primary, secondary, success, danger, warning, info, light, dark) - Pill shape option (rounded badges) - Icon support (left or right position) - Size variants (sm, md, lg, xl) - Position variants (for badges on buttons/headings) - Custom background and text colors - Notification badge with counter - Link badge option - Customizable classes and attributes Parameters: ----------- - text: Badge text/label (required) - variant: "primary" | "secondary" | "success" | "danger" | "warning" | "info" | "light" | "dark" (default: "primary") - pill: true | false - Rounded pill shape (default: false) - icon: Bootstrap icon class (optional, e.g., "bi-check-circle") - icon_position: "left" | "right" (default: "left") - icon_size: "sm" | "md" | "lg" (default: "sm") - size: "sm" | "md" | "lg" | "xl" (default: "md") * sm = 0.65rem font, 0.35rem padding * md = 0.75rem font, 0.5rem padding (default Bootstrap) * lg = 0.875rem font, 0.6rem padding * xl = 1rem font, 0.75rem padding - position: "top-right" | "top-left" | "bottom-right" | "bottom-left" (optional, for positioned badges) - bg_color: Custom background color class (optional, e.g., "bg-wood") - text_color: Custom text color class (optional, e.g., "text-white") - href: URL for link badge (optional) - target: "_blank" | "_self" (default: "", for link badges) - additional_classes: Extra CSS classes (optional) - id: Badge ID attribute (optional) Usage: ------ Basic badge: {% include components/badge.html text="New" variant="primary" %} Pill badge: {% include components/badge.html text="Featured" variant="success" pill=true %} Badge with icon (left): {% include components/badge.html text="Verified" variant="success" icon="bi-check-circle-fill" icon_size="sm" %} Badge with icon (right): {% include components/badge.html text="Download" variant="info" icon="bi-download" icon_position="right" %} Small badge: {% include components/badge.html text="Beta" variant="warning" size="sm" %} Large badge: {% include components/badge.html text="Premium" variant="danger" size="lg" pill=true %} XL badge with icon: {% include components/badge.html text="Certified" variant="success" size="xl" icon="bi-award-fill" %} Notification badge (counter): {% include components/badge.html text="99+" variant="danger" pill=true size="sm" %} Link badge: {% include components/badge.html text="Visit Documentation" variant="primary" href="/docs" icon="bi-book" %} External link badge: {% include components/badge.html text="GitHub" variant="dark" href="https://github.com" target="_blank" icon="bi-github" %} Custom color badge: {% include components/badge.html text="Wood Theme" bg_color="bg-wood" text_color="text-white" %} Badge on button (positioned): Multiple badges:
